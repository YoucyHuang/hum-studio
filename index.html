  1. 1哼一段旋律

  3. 3导出视频发小红书

1旋律来源01 / SOURCE

按一下，开始录音
对着手机哼一段，哼完再按一下就停

支持手机录音常见格式（m4a / mp3 / wav 等），电脑上也可以直接把录音文件拖进页面。哼的时候用“嗯 / 啦 / 嘟”，一个音一个音分开哼，识别会更准。

2识别出的旋律02 / MELODY

上传或录制哼唱后，这里会显示识别出的音符。拖动音符可以改音高、位置和长短。

3编曲与音轨03 / MIXER

每条音轨都能单独换音色、调音量；M = 静音，S = 只听这一轨。同一段旋律可以加好几条“主旋律”叠出混合音色。

所有处理都在你的手机 / 电脑里完成，录音不会上传到任何地方。作品会自动保存在这台设备上。
